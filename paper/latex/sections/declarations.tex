\subsection*{Data Availability}
The code used to generate the results in this study, including the full training,
evaluation, and inference implementation (not pseudocode), configuration files, and
documentation required to reproduce all reported experiments, is publicly and
permanently available at
\url{https://github.com/nishimaliknitj/ODFE-OBM-OACL-RSDetection}.

The DIOR, DOTA, and FAIR1M datasets used for training and validation are publicly
available third-party benchmarks released by their original authors and can be
obtained from their official sources:
\begin{itemize}
  \item DIOR: \url{https://gcheng-nwpu.github.io/#Datasets}
  \item DOTA: \url{https://captain-whu.github.io/DOTA/dataset.html}
  \item FAIR1M: \url{https://www.gaofen-challenge.com/benchmark}
\end{itemize}
Dataset preparation instructions matching the directory structure expected by our
code are provided in the repository at \texttt{docs/data\_preparation.md}.
